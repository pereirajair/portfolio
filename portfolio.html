Como ler esta galeria

Cada cartão representa um projeto do data.json. À direita você vê todas as imagens cadastradas para aquele projeto, organizadas em uma faixa horizontal rolável.

  • Plataformas web e sistemas de governo (dashboards, portais e chatbots).
  • Aplicativos mobile nativos para iOS/Android.
  • Jogos mobile publicados em App Store / Google Play.
  • Iniciativas estratégicas para o Governo do Estado do Paraná.

Dica: passe o mouse sobre uma imagem para ver mais contraste, e use a rolagem horizontal na galeria de cada projeto para navegar por todas as telas.
